# Smart Electrical Connection Health Monitoring

### Simulation-Based Predictive Fault Detection Using MATLAB

## Overview

This project presents a MATLAB-based simulation framework for monitoring electrical connection health through contact resistance estimation and fault detection.

The objective is to identify gradual electrical connection degradation, detect sudden faults, and evaluate the effects of measurement noise on alarm reliability.

The system combines conventional resistance estimation, sliding-window least squares (LS), hybrid decision logic, and grid search parameter optimization.

**Software:** MATLAB R2025a  
**Application:** Electrical Engineering, Fault Detection, Predictive Maintenance  
**Validation:** Synthetic simulation data

## Methodology

The contact resistance is estimated using measured current and voltage drop.

Conventional resistance estimation:

\[
R = \frac{V}{I}
\]

Sliding-window least-squares estimation:

\[
\hat{R} = \frac{\sum I_k V_k}{\sum I_k^2}
\]

The hybrid detection algorithm uses a short-window resistance estimate for faster response and an LS estimate for additional confirmation.

A separate trend-based early warning algorithm estimates the remaining number of samples before a predefined critical resistance threshold is reached.

## Simulation Scenarios

Four scenarios are evaluated:

1. Healthy electrical connection
2. Gradual contact resistance degradation
3. Sudden contact resistance fault
4. Load current fluctuation without connection degradation

Measurement noise is simulated using Gaussian voltage noise at standard deviations of 2, 5, 10, and 20 mV.

## Parameter Optimization

Grid search evaluates 18 combinations of:

- Fast-filter window length
- Critical alarm confirmation count
- LS confirmation margin

The optimization objective balances false alarms, premature critical alarms, missed detections, and detection delay.

Selected configuration:

| Parameter | Value |
|---|---|
| Fast filter window | 2 samples |
| Critical alarm confirmation | 3 samples |
| LS confirmation margin | 0.002 Ω |
| Critical resistance threshold | 0.075 Ω |
| LS estimation window | 7 samples |

## Results

An independent synthetic test set, generated separately from the parameter-selection data, produced the following results:

| Metric | Result |
|---|---:|
| False alarm rate | 0.00% |
| Premature critical alarm rate | 0.75% |
| Missed critical fault rate | 0.00% |
| Mean critical detection delay | 4.75 samples |
| Gradual-degradation early warning rate | 99.50% |
| Mean early warning lead | 14.47 samples |

These results are aggregated across the evaluated synthetic scenarios and noise conditions. They do not establish real-world system reliability.

A separate baseline comparison illustrates the trade-off between premature alarm reduction and detection latency.

## Running the Project

1. Open MATLAB R2025a.
2. Set the current folder to the project directory.
3. Run `Hibrit_Parametre_Optimizasyonu.m` to generate optimization results.
4. Run `Kablo_Sagligi_Final.m` for the hybrid algorithm comparison.
5. Run `Kablo_Sagligi_Dashboard.m` to generate the dashboard.

The dashboard requires the optimization and comparison CSV files generated by the earlier scripts.

## Limitations

This project uses simulated current, voltage, and contact resistance data. No physical sensor measurements or hardware experiments have been performed.

The resistance thresholds are illustrative simulation parameters, not validated safety limits.

The early warning rate measures whether a warning occurs before the simulated threshold crossing, not the accuracy of the predicted remaining time.

Future work includes low-voltage DC hardware testing, calibrated current and voltage acquisition, and validation using real electrical connections.
